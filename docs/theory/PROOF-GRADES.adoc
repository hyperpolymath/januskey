= Proof Witness Grades (PROOF-POLICY §8)
:toc: preamble
:icons: font

This page grades januskey's proof claims in the vocabulary its owner's estate
mathematics architecture uses, and records the receipt for every grade. It is
the answer to a single question a reader of `PROOF-NEEDS.adoc` should not have
to reconstruct: *which of these claims is a proof, and how good a proof is it?*

It grades nothing by confidence. There is no percentage anywhere in this
repository, and none is introduced here.

[NOTE]
====
*PWG census, theory theorems of this repository (denominator 6):*
`PWG-3` 5 (G-1, T-1, T-2, T-3, E-1m) · `PWG-2i` 0 · `PWG-2ii` 0 · `PWG-1` 0 ·
`ungraded` 1 (G-3, `OPEN`: no Agda statement yet). `+foundation-diverse`: none.
Axioms: none. The denominator is the ledger rows whose source of truth is, or is
to be, an Agda theorem. E-1 (a security property of the implementation; its
model half is E-1m), the MPR row (a refinement claim about Rust, which §1 sends
to Creusot and Verus) and G-2 (a bridge, `ASSUMED`) are outside it.
====

== What governs the grades

Since the owner ruling of 2026-11-04, `PROOF-POLICY.adoc` §8 is normative for
grades, and they are written with their prefix: `PWG-3`, `PWG-2i`, `PWG-2ii`,
`PWG-1`, or `ungraded`. The mathesis brief that first proposed the ladder is
kept for provenance only; where the two differ, §8 governs. This page was first
written against the brief (2026-11-01) and was brought in line with §8 on
2026-11-09.

januskey's own five-status ledger vocabulary (`PROVEN`, `TESTED`, `ASSUMED`,
`DESIGNED`, `OPEN`) is the estate's claim vocabulary and is unchanged by any of
this. A grade is a second axis laid over it, not a replacement: a row is
`PROVEN` *because* a named artefact checks it, and separately has (or has not) a
Proof Witness Grade.

== The PWG-3 receipt

The theory artefacts are three Agda modules:

* `verification/proofs/agda/Reversibility.agda` — the Loss grade algebra:
  lossless traces have only lossless steps, obliteration absorbs, and a
  wrap/unwrap pair with a cancellation premise is a grade-𝟙 two-step trace.
* `verification/proofs/agda/TransactionAtomicity.agda` — rollback restores the
  state the transaction began in; the `TransactionManager` lifecycle keeps its

=== Why it stops at PWG-3

PWG-2i and above would require an Agda → Dedukti → Rocq/Lean transport or a
re-proof, with the outcome recorded as `transported`, `re-proved` or
`unavailable` (PROOF-POLICY §2). That work has not been done, is not claimed,
and would not change what these modules prove: §2.2 is explicit that compiling
in a second prover does not establish the same proposition unless the
correspondence is checked too.

== The §2.1 invocation: adopted, and measured (2026-11-01)

PROOF-POLICY §2.1's canonical form is
`agda --safe --without-K --cubical-compatible <module.agda>`. Until this branch
the gate ran `--safe --without-K --no-libraries --ignore-interfaces
--double-check` without the cubical flag, and an earlier revision of this page
predicted that adding it would fail, because the flag is *infectious* (direct
imports must use it too) and every module of the pinned sibling opens with
`{-# OPTIONS --safe --without-K #-}`.

**That prediction was wrong and is withdrawn.** With Agda 2.6.4.3 installed in
the sandbox (PyPI wheel `agda==2.6.4.3.post1`, reporting
`Agda version 2.6.4.3-56f5f56`, the same version CI pins), the canonical
invocation type-checks both modules:

[source,text]
----
$ agda --safe --without-K --cubical-compatible --no-libraries \
       --ignore-interfaces --double-check \
       -i verification/proofs/agda -i _build/dependencies/resource-algebra/src \
       verification/proofs/agda/Reversibility.agda
   → exit 0, 14 × warning: -W[no]UnsupportedIndexedMatch

$ … verification/proofs/agda/TransactionAtomicity.agda
   → exit 0, 16 × warning: -W[no]UnsupportedIndexedMatch

$ AGDA=/tmp/tc/bin/agda bash scripts/check-agda.sh
   → [PASS] refused as expected: tests/reject-agda/{CommitWhenIdle,ForwardRollback,HiddenLoss,ReviveAfterObliterate}
   → [check-agda] OK
----

Agda warns where the earlier reading expected it to refuse: a `--without-K`
import is accepted, and what it reports is that particular clauses — the
sibling's `≤-trans`, and `obliterate-absorbs` here — will not compute when
applied to cubical transports. That is a statement about computation under
transport, not about the propositions these modules prove, so the gate keeps the
warnings visible rather than silencing them with `-WnoUnsupportedIndexedMatch`.

`scripts/check-agda.sh` now runs the canonical invocation, so januskey matches
§2.1 exactly and is still stricter in two other respects (`--ignore-interfaces`
re-checks the sibling from source instead of trusting compiled interfaces;
`--double-check` re-verifies the type-checker's own work).

=== Receipt bookkeeping for that change

The local run above is recorded as **reproduction** only: same prover version,
PyPI provenance instead of Debian, and no CI provenance (PROOF-POLICY §2.3:
receipts of execution come from CI). The CI receipt it was waiting for now
exists: the table in §The PWG-3 receipt cites run 42076969251, which ran the
canonical invocation on all three modules, and the receipts from before the
flag changed are marked `superseded` there.

One related inconsistency is an open obligation, not a claim: the Agda version
is pinned twice in CI and the two pins differ — `agda-proofs.yml` installs
2.6.4.3 (the receipt above), while `dashboard-check.yml` installs 2.6.3 on the
Idris2 image so it can run the PROVEN rows' checkers. A green dashboard
therefore does not extend the receipt at 2.6.4.3. One version, one receipt:
pinning the dashboard job to the same Agda is the fix.

=== Upgrade path, measured

`agda==2.7.0.1` runs in the sandbox once its wheel's missing `data/lib` is

=== Engineering contracts — no Proof Witness Grade applies

Seven `PROVEN` rows are Idris2 theorems about this ABI: A-1, A-2, C-1, C-2,
C-3, C-4, C-5, checked by
`idris2 --typecheck src/abi/januskey-abi.ipkg`. Under PROOF-POLICY §1 these
are interface and wire-format contracts, so the theory ladder does not grade
them — they are `PROVEN` in the ledger's own vocabulary and that is the whole
of the claim. The `Rust/SPARK` shorthand is withdrawn; the mapping that
replaces it is Rust → **Creusot**, Ada → SPARK, API/ABI → Idris2, theory →
Agda.

The same heading covers every `TESTED` row (23): a test proves behaviour was
observed, never that it always holds. G-2 (the Idris2 ↔ Agda correspondence) is
`ASSUMED` by transcription and would have to become mechanical before any
"every operation is reversible" theorem could cite both halves.

== The epistemic rewrite: E-1 becomes E-1m

The one claim with an inheritance, rather than an invention, behind it. januskey's
Idris2 ABI carries `Knows : Agent → Type → Type` (`Types.idr` §Level 12), a
discrete epistemic modality inherited from the estate's epistemic-types work. It
could not state the security claims the ledger attributed to it:

* `Knows Adversary a` is uninhabited **by construction** — there is no Adversary
  constructor — so "an attacker cannot recover …" (E-1) was a property of a
  datatype. The repository's own comment says as much: "a property of this
  model, not a security proof".
* "The system forgets the old key" was **unstateable**, because `Knows` has no
  negative form. The lemma was deleted rather than repaired, and the ledger
  records the deletion.

`verification/proofs/agda/Epistemic.agda` replaces the modality with one whose
ignorance is a proposition. Knowledge is indiscriminability over an observation
— an agent knows φ in *x* when φ holds in every world it cannot tell apart from
*x* — so:

* ignorance is `¬ Knows`, proved by exhibiting a world that looks the same and is
  not (`adversary-ignorant`, over two worlds that differ only in the store);
* obliteration is a change to the store channel, and recovery is a `Σ` that
  becomes empty (`obliterate-cuts-recovery`), with the adversary's ignorance
  surviving the operation because its observation did not change
  (`obliterate-ignorance`);
* rotation is an update to a `usable` predicate, so "no agent can use the old
  key" is a theorem with a Bool on the right (`rotate-forgets-old`), and the
  deleted Idris lemma now has a proved counterpart. It follows from the
  definition of `rotate`; its content is that the statement is now
  *expressible*, which the Idris modality could not manage, not that it is deep.

Two fixtures pin the refusals: `AdversaryKnows.agda` (asserting the two stores
are identical — refused, `2 != 1`) and `OldKeyStillUsable.agda` (asserting the
old key survives rotation — refused, `!= true`).

What this does **not** do is move E-1. A model of channels is not a model of
cryptography: that the store channel is the only one an attacker has, and that a
key which is not `usable` cannot decrypt, are assumptions (X-1), and E-1 stays
`OPEN`. The Idris module is unchanged — its typecheck status, its deleted lemma
and its comments now pointing here — because the theory belongs in Agda under
PROOF-POLICY §1 and the ABI belongs in Idris2.

== Reporting rules this repository follows

* No percentage, ever. Where a "completion" figure exists elsewhere in the
  tree it is a project-plan measure, not a proof measure, and it is not a grade.
* Every grade names its receipt: commit, prover, prover version, flags,
  sibling pin. The receipt above is the only one of its kind here.
* A receipt is invalidated by a change to a graded artefact, to its checker or
  to its pin, and is then re-earned by the next run, not carried forward.
* A receipt that is no longer current carries `state: superseded` (a newer
  receipt replaced it) or `state: regressed` (the source no longer checks), with
  the reason (PROOF-POLICY §8.4). These are receipt states, not status tokens,
  and neither receipt is deleted from the history.
* `AGDA-PENDING` is the correct correspondence state for a module committed but
  not yet checked. No row in this repository is in that state today: the five
  graded rows are `AGDA-VERIFIED` at the commit above. Their Rocq and Lean legs
  have not been attempted, so each is `OPEN` with no route and no §2.2 record,
  and the grade is `PWG-3`. They are not `unavailable`: under §2 that route
  means a leg that cannot be built, and a hand re-proof is always available as
  the fallback, so the legs are owed, not excused (§8.4.1).
* Grade counts appear only as the census at the top of this page: a count per
  rung, with the denominator and the `ungraded` rung in the same line.
